**Stream:** docs · **Depends on:** Q1, B1, B2, B3, V1, V3, V6, V7, E1, E2, E3, U1–U5, P7 (runs **last**, once these are merged or explicitly deferred)

## Description

The docs still describe "WA ParkStay Bookings": an automated ParkStay booking tool with a login screen, Dashboard and Skip The Queue.

- `README.md:1-48` and `docs/README.md:1-3` both say so.
- About 196 markdown lines repo-wide carry the old names.
- `docs/parkstay-api/ENDPOINTS.md` (1,297 lines) is "largely guesswork" (parkstay-api-review). It lists routes such as `/auth/login`, `/account/` and `/queue/status/` that do not exist in the DBCA backend.
- 15 stale status files litter the repo root (`FINAL-STATUS.md`, `SUCCESS.md`, `READY-TO-RUN.md`, …).

After this task, a newcomer reading the README understands three things: WA Stay is a WA accommodation booking app; ParkStay WA is its first provider; and existing users upgrade automatically. A developer can add a provider from the guide alone, and `CLAUDE.md` matches the code.

As a prospective user, I read the README and know what WA Stay does, how to download it and what happens to my ParkStay Bookings data. As a contributor, I follow `docs/providers/adding-a-provider.md` and get a compiling provider that shows up in the registry.

## Edge Cases

- **A feature was deferred.** For example, if V6 sign-in or U3 import was cut, document only what shipped and say "coming soon". Never describe planned behaviour as shipped.
- **Gmail OTP is unused in v2 flows** (DocQ4). Say so plainly, rather than keeping four setup guides.
- **Endpoint status changed during V3** (a route probed or newly used): `client.ts` is the source of truth. Re-date the status.
- **Moved files break inbound links** (e.g. `CLAUDE.md` → `docs/SITE_SNIPER.md`, `resources/README.md:267-268` → `docs/development.md`). The link test catches these.
- **Windows paths in Markdown.** Escape backslashes inside code spans only.
- **No token** when generating screenshots: list-mode shots are acceptable. Note it in the PR.
- **Secrets.** Never paste a real token, even a public `pk.` one. Use `pk.your-token-here`.
